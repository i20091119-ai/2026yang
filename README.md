# 백호장군 안이명: 숫자 베기

양산의 임진왜란 의병장 **안이명(安以命) 장군**을 주인공으로 한 소인수분해 웹 게임입니다.
경남수학문화관 양산수학체험센터(GNMC)용으로 만들었으며, 초·중학생을 대상으로 합니다.

아래에서 튀어오르는 숫자를 그어서 베면 **합성수는 두 약수로 나뉘고**, 나뉜 수가 아직 합성수면 다시 벨 수 있습니다.
**소수**는 나눌 수 없으므로 그냥 보내야 합니다.

## 규칙 요약

| 항목 | 내용 |
| --- | --- |
| 목숨 | 3개. 합성수를 베지 못하고 떨어뜨리면 하나 잃습니다. |
| 스테이지 | 안이명 장군의 전투 경로 순서: 양산 → 밀양 → 청도 → 울산 → 대구. 일정 횟수 나누면 "양산성을 지켜냈다!" 같은 완료 메시지가 뜨고, 화면이 어두워졌다 새 배경으로 밝아지며 다음 진이 시작됩니다. 전환 중에는 남은 숫자가 벌칙 없이 사라집니다. |
| 소수를 벴을 때 | 양산·밀양: 벌칙 없음 (배우는 단계) / 청도·울산: 1점 감점 / 대구: 목숨 하나 손실 |
| 점수 | 한 번 나눌 때 배수만큼 획득. 두 조각이 모두 소수면 "완전분해" 보너스 +1 |
| 배수 | 연속으로 4번 맞게 벨 때마다 x1 → x2 → … → x5. 놓치거나 벌칙 스테이지에서 소수를 베면 초기화 |
| 연속 보너스 | 연속 성공 횟수가 화면에 "연속 N회!"로 뜨고, 5회마다 보너스 점수(5회 +2, 10회 +4, 15회 +6 …) |
| 진행 표시 | 화면 왼쪽 위에 이번 진의 임무 진행(왜군 7 / 12)이 막대로 표시됩니다. 마지막 진에서는 총공세까지 남은 초, 총공세 시작 후엔 1~3단계와 최대가 표시됩니다. |
| 칼 | 톡 치면 그 자리에서 칼을 휘두르고(짧은 대각선 베기), 누른 채 그으면 손끝을 따라 칼이 움직입니다. 진이 오를 때마다 목검 → 철검 → 환도 → 백호검 → 백호장군검으로 등급이 올라갑니다. |
| 총공세 | 5진 대구 도착 30초 뒤부터 45초에 걸쳐 생성 간격, 동시 등장 수, 낙하 속도가 점점 올라갑니다. |
| 난이도 | 의병(20 이하) / 장수(60 이하) / 백호장군(150 이하). 숫자 범위와 속도, 동시 등장 수가 다릅니다. |
| 순위표 | 난이도별 상위 10위. 이름은 기록하지 않고 점수만 남깁니다. |

## 소수와 합성수 배우기

시작 화면의 "소수란?" 버튼과 게임 방법 4번 슬라이드의 링크로 들어갑니다.
1~100 숫자판에서 숫자를 누르면 소수인지 합성수인지와 약수 짝(12 = 2 × 6 = 3 × 4)을 보여 주고,
"체로 걸러 보기"를 누르면 에라토스테네스의 체가 한 단계씩 소수를 골라내는 애니메이션이 나옵니다.

### 업데이트 방식

앱은 얇은 껍데기입니다. 인터넷이 되면 항상 GitHub Pages 의 최신 게임을 불러오고, 인터넷이 안 될 때만 앱 안에 담긴 사본을 씁니다.
그래서 **이 저장소에 푸시하면 설치된 앱에서도 다음에 실행할 때 바로 반영**됩니다. 다시 설치할 필요가 없습니다.

푸시할 때마다 GitHub Actions(`.github/workflows/apps.yml`)가 exe 와 apk 를 새로 만들어 Releases 의 `latest` 에 덮어씁니다.
오프라인 사본까지 최신으로 맞추고 싶을 때만 새 파일을 받아 다시 설치하면 됩니다.

- 윈도우 앱: `desktop/` (Electron). 로컬에서 만들려면 `cd desktop && npm install && npm run dist`.
- 안드로이드 앱: `android/` (WebView). 로컬에서 만들려면 Android SDK 를 설치한 뒤 `gradle -p android assembleRelease`.
- `android/keystore/baekho.jks` 는 APK 서명용 키입니다. 스토어 배포용이 아니라 같은 키로 서명해야 덮어쓰기 설치가 되기 때문에 저장소에 함께 둡니다.

## 공용 점수판 설정 (Supabase 무료 티어)

1. <https://supabase.com> 에서 새 프로젝트를 만듭니다.
2. SQL Editor 를 열고 `supabase/schema.sql` 내용을 붙여넣어 실행합니다.
   테이블 `scores` 와 RLS 정책(익명 읽기·추가만 허용)이 만들어집니다.
3. Project Settings > API 에서 **Project URL** 과 **anon public** 키를 복사합니다.
4. `js/config.js` 의 `SUPABASE_URL`, `SUPABASE_ANON_KEY` 에 붙여넣습니다.

anon 키는 브라우저에 공개되는 키입니다. 테이블에 수정·삭제 정책이 없으므로 이 키로는 점수를 읽고 추가하는 것만 가능합니다.
설정하지 않으면 점수는 각 브라우저의 localStorage 에만 저장됩니다.

## 안이명 장군

조선 중기 양산 출신, 본관 광주(廣州). 1590년(선조 23) 무과 합격. 별칭 백호장군(白虎將軍).
1592년 임진왜란 때 아버지 안근, 형 안시명, 사촌 안신명, 당숙 안도수 등과 함께 의병을 일으켜 양산을 지켰고,
양산 함락 후에도 밀양·청도·울산·대구 등지에서 왜군과 싸웠습니다.
유적으로 안이명 묘(상북면 대석리), 소계서원(1783년 건립, 상북면 소토로 38), 효충사가 있으며
무과교지는 경남유형문화재 제149호입니다.
