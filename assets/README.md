# 그림 파일 넣는 곳

효과음은 코드로 합성한 것이라 더 좋은 소리가 있으면 같은 이름으로 덮어쓰면 됩니다.

WAV 원본은 용량이 커서(19MB) 저장소에 두지 않고 MP3(1.7MB)로 바꿔 넣었습니다. 새 곡으로 바꿀 때도 MP3로 변환해 같은 이름으로 넣으면 됩니다.

소리 파일도 없으면 그냥 조용히 진행되고, 시작 화면과 일시정지 화면의 버튼으로 끄고 켤 수 있습니다.

배경은 세로로 잡은 폰에서도 잘리지 않게 **중요한 요소를 가운데 세로 1/3 안에** 두면 좋습니다.
게임 중에는 흰 숫자가 잘 보이도록 배경 위에 어두운 막(28%)이 자동으로 씌워집니다.
그래서 배경은 너무 밝지 않고, 가운데가 비교적 단순한 그림이 좋습니다.

## 제미나이(또는 다른 이미지 생성 AI)에 넣을 프롬프트 예시

공통으로 앞에 붙일 스타일 설명:

> 한국 전통 수묵화와 밝은 모바일 게임 일러스트를 섞은 스타일, 초등학생이 좋아할 만한 또렷한 색감,
> 텍스트나 글자 없음, 가로 16:9, 화면 가운데는 비교적 단순하게 비워 둘 것.

배경 5장:

1. **양산** — "임진왜란 시기 조선의 양산 읍성 성벽과 멀리 보이는 영축산 능선, 새벽빛, 의병들의 깃발이 성 위에 꽂혀 있음"
2. **밀양** — "밀양 영남루가 보이는 강가, 낙동강 지류 위로 해가 뜨는 아침, 안개"
3. **청도** — "청도의 산골짜기 길, 소나무 숲과 돌담, 낮의 햇빛"
4. **울산** — "울산 태화강과 대나무 숲, 저녁노을, 멀리 왜성"
5. **대구** — "대구 팔공산 아래 넓은 들판, 밤, 보름달과 횃불"

캐릭터 1장:

> "조선 중기 무관 안이명 장군, 별명 백호장군(흰 호랑이 장군). 흰 호랑이 무늬가 들어간 갑옷과 투구,
> 손에 검을 든 늠름하지만 친근한 표정, 초등학생용 게임 캐릭터 느낌의 귀여운 3등신 비율,
> 정면 상반신, 배경 투명(PNG), 텍스트 없음"

원하면 난이도 아이콘(의병·장수·백호장군)이나 게임 오버 화면용 그림도 같은 방식으로 추가할 수 있습니다.
